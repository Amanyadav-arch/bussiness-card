# Digital Business Card

This is a simple digital business card built using HTML and CSS.  
It displays personal information in a clean card layout with an avatar image, name, role, and location.

This project is part of my frontend development learning journey as I work toward becoming a full-stack developer.

## Features
- Clean card UI design
- Profile image display
- Responsive layout
- Simple and readable HTML structure
- CSS styling for modern card appearance

## Technologies Used
- HTML5
- CSS3

## What I Learned
- Structuring HTML layout
- Linking external CSS files
- Styling UI components with CSS
- Creating card-based designs
- Using images inside a layout

## Future Improvements
- Add hover effects
- Make the card fully responsive for mobile
- Add social media links
- Improve typography and spacing
